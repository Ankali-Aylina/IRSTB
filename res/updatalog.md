## v4.4.0.0

- 新增**固件升级（OTA）**：在「关于」页选择 `.bin` / `.hex` 固件，经蓝牙把新固件写入下位机并激活
  - 流程：应用受理升级请求后复位 → 常驻引导程序接管 → 重新建立升级会话 → 分帧传输 → 校验并激活
  - 全程显示进度百分比与阶段状态（进入升级模式 / 正在传输 / 等待校验 / 激活），可随时取消
  - **两道校验**：逐帧 CRC16 + 逐帧应答重发（丢帧只重发那一帧）；整镜像写完后再由下位机回读重算
    CRC32，一致才激活
  - 帧长自动适配：某帧连续被拒时自动把负载减半重试（蓝牙 MTU 小于帧长时自愈）
  - 升级完成后自动重新查询下位机版本（蓝牙由透传模块保持、MCU 复位不断链，否则界面会一直显示旧版本号）
  - 失败原因直接可读（未连接 / 固件过大 / 下位机固件不是 OTA 版本 / 未烧录引导程序 / 校验失败）
  - ⚠️ 需要下位机已烧录引导程序（占用 0x0000~0x4FFF）且应用运行在 0x5000，协议见固件仓库 `boot/ota.h`
- 修复：**温度图标在报警时显示为发暗的红褐色**（而不是正常的红色）
  - 根因：图标着色用的是「目标色 × 源图亮度」，而 `cpuTemp-red.png` 本身就是红图，红色叠红色越描越黑
  - 改为使用白色源图，颜色完全由主题色决定；`gpuTemp-red.png` 同理
- 修复：**蓝牙图标在「断开」「失败」状态下颜色不对**（断开被压成近黑、失败被压成暗褐）
  - 根因同上：`BLE_Off.png` / `BLE_Error.png` 本身就是猩红色
  - 三个蓝牙图标其实是同一个字形，已统一为白色源图，颜色交给状态决定
- 修复：**关机散热提示条的警告图标一直不显示** —— `warning_line.png` 在 v4.0.0.0 的 QML 迁移中被误删出
  QRC，而界面一直在引用它（缺失时不会报错，只是图标空白）
- 修复：「**更新日志**」对话框直接显示 Markdown 源码（`#`、`##`、`-`、`**` 等符号原样出现），
  现在按 Markdown 正确渲染（标题分级、列表项目符号与缩进、粗体、行内代码）
- 修复：退出提示里「**最小化到托盘**」点了没反应（弹窗关闭后取不到窗口，指令静默失败）
- 改进：蓝牙「**连接中 / 重连中**」状态显示为天蓝色，与搜索进度条同色，进行中状态一目了然
- 改进：设置页的两个开关改为**带滑动动画的开关**（滑块平滑滑动 + 轨道颜色渐变），
  替换原来在 `switch-on.png` / `switch-off.png` 两张图之间瞬切的做法
- 改进：**温度图标与蓝牙图标改为 QML 矢量绘制**，替代原来的位图
  - CPU / GPU 温度图标共用同一套芯片几何，只换内部标记（方格 / 菱形），风格天然一致
  - 走技术插图的画法：粗线画轮廓（封装 / 焊盘 / 温度计管身）+ 发丝线画细节（芯片核心 / 刻度），
    封装左上角 45° 倒角并带 Pin-1 实心标记，引脚画成四边短粗焊盘，
    温度计用长短交替的分级刻度 + 球泡内实心液面
  - 蓝牙图标：四角定位角标（技术图纸的 registration mark）+ 加宽符文，保证小尺寸下笔画不糊
  - 任意尺寸都清晰；颜色直接由状态决定，不再依赖位图着色，也就从根上避开了
    「带色源图再做色相着色会越描越暗」这一类问题
  - 报警时只换描边颜色，不再需要「正常 / 报警」两份图标来回切
  - 同时移除 `cpuTemp.png` / `gpuTemp.png` / `BLE_On.png` 三个资源
- 改进：设置页去掉重复的「设置」+「外观」双层标题（两者字号颜色相同、没有层级，且「设置」与导航栏重复）
- 新增**特别主题「NASA 朋克」**（设置 → 风格 → NASA）
  - 风格：1960–80 年代 NASA 航天器工业设计与技术文档系统，理性、干净的乐观复古未来主义（不是赛博朋克）
  - 配色：烤漆白 `#F4F3EF` 底、NASA 蓝 `#0B3D91`、金属灰 `#A8ACAF / #6E7378 / #43484C`；
    信号红 `#E4002B` 只用于关键警示与字标点缀，Kapton 金仅出现在字标等 1~2 处焦点元素上
  - 顶部改为**深色仪表板标题栏** + 黄黑危险斜纹 + 文档控制条（`DOC NO. / REV / PAGE` 等宽小字元数据）
  - 所有面板改为**方角（0~2px）+ 1px 金属细边 + 四角铆钉**；页面底透出极淡的双尺度蓝图网格
  - 温度卡片：等宽大字号读数 + 下方细刻度条；数值与技术标签改用等宽字体，标题改用 Nasalization Rg
  - **亮 / 暗随明暗设置自动切换**：烤漆白底 + 深色仪表板，或深色仪表板底 + 提亮的金属边；
    蓝图蓝 / 信号红 / 火箭橙 / Kapton 金在暗底上均做了提亮以保证可读
  - 需要系统已安装 **Nasalization Rg** 字体；未安装时自动回退，不影响使用
- 改进：**主题设置拆成两块独立面板**：「主题模式」（跟随系统 / 浅色 / 深色）与「风格」（默认 / NASA），
  与「背景材质」并列、各自一行
  - 风格与明暗互相独立，因此不再需要「NASA 亮 / NASA 暗」两个独立按钮 —— 选 NASA 后明暗仍由「主题模式」决定
  - 旧配置（单一 `ThemeMode=3/4` 表示 NASA 亮/暗）会自动迁移到「风格=NASA + 对应明暗」并写回新键，无需用户重设
- 内部：QML 界面由单个 1381 行的 `main.qml` 拆分为 19 个组件文件 + `qmldir`（新增单例需随 QRC 一起登记）
- 内部：清理不再使用的图标资源，exe 体积略减

## v4.3.0.0

- 新增**关机散热**：一键让风扇满速运行设定时长（1~10 分钟）后自动断电关闭
  - 倒计时由下位机独立计时，期间蓝牙断开、退出程序、关闭电脑都不中断散热
  - 散热结束后自动切回自动模式，风扇随后继续按温度调速
  - 散热结束、指令下发失败时，右下角弹出系统通知（窗口最小化到托盘也能看到）
  - 新增设置项「系统通知」开关，可随时关闭
- 新增下位机状态回传：通过蓝牙通知接收下位机上报的散热状态，并在日志中显示
- 蓝牙底层库升级：新增写入结果查询（可确认指令是否真的写进设备），修复回调内重入死锁
- 修复：蓝牙断开后反复弹出重复提示、状态回传的一行被拆成多条通知时的解析错误
- 修复：**资源提取缓存判据失效** —— 同一版本号下更换内嵌 DLL 时旧文件不会被更新
  （改用内容清单 + 版本变化时整体重提取；原先"按大小比对"的判据在 QRC 压缩存储下无效）
- 下位机固件同步更新：风扇 PWM 频率提升至 25 kHz（消除低速档啸叫），关机散热指令协议与状态回传
